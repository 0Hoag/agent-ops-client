# Production client container

Build the production image with `docker build -t agent-ops-client .`. The first stage compiles the existing Rspack application; the runtime stage is the unprivileged Nginx image and serves on port 8080. Run with `-p 8080:8080 -e API_UPSTREAM=http://api:8080` to route same-origin `/api/` requests to the configured upstream. `API_UPSTREAM` is required; there is no configured default. Set it to the API service's reachable HTTP origin. The Nginx proxy preserves the complete request path and query string, Authorization and websocket upgrade headers; unknown frontend paths fall back to `index.html`.

`APP_API_URL` is compiled into the bundle at build time, so the production image does not substitute it at runtime. The normal build uses the empty default, making API requests same-origin. `scripts/test-client-container.sh` builds and exercises the image against disposable deterministic HTTP and websocket fixtures. Those fixtures validate proxy routing and header forwarding only; they are not real API integration tests.
